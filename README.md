# 🤖 KOD AJANI

### Eğitici Robotik Kodlama ve Algoritma Oyunu

KOD AJANI, öğrencilerin algoritmik düşünme, problem çözme ve kodlama becerilerini geliştirmek amacıyla hazırlanmış web tabanlı bir eğitim oyunudur.

## 🚀 Proje Özellikleri

- Etkileşimli robotik kodlama görevleri
- Yön komutlarıyla robot hareketi
- Bölüm ve görev sistemi
- Kilitli bölümlerin tamamlandıkça açılması
- XP puan kazanma sistemi
- Öğrenci dostu oyun arayüzü

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript

## 🎮 Oyunu Çalıştırma

1. Projeyi bilgisayarınıza indirin.
2. Proje klasörünü Visual Studio Code ile açın.
3. index.html dosyasını tarayıcıda açın.
4. Gerekirse Live Server eklentisini kullanın.
